# Media credits

Everything in this folder is a screenshot or a screen recording of this repository's web interface, captured on 2026-10-04 with `docs/examples/capture-media.mjs` from a local build that read the public deployment (read-only `GET` requests).

| Content | Source | Terms |
|---|---|---|
| Series titles, overviews, years, keywords, cast and crew, graph relations shown on the pages | [TMDB](https://www.themoviedb.org) via the project's API | This product uses the TMDB API but is not endorsed or certified by TMDB. |
| One series poster (Breaking Bad, TMDB id 1396) visible in `series-breaking-bad.png` and `mobile-series.png` | TMDB's image CDN, loaded by the page | poster artwork belongs to its rights holders; shown only to illustrate the interface, with the TMDB attribution above |
| Interface, layouts, graph drawings | this repository | MIT, see `LICENSE` |

No other third-party images are included. The 3D view and the graph canvases are rendered by the app itself from the API responses.
